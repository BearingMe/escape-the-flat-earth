# .harness — Progress Protocol

No task lists. Progress is tracked as **milestones** and **checkpoints**.

- `milestones/` — what we want to reach. One file per milestone, written when a goal is set.
- `checkpoints/` — our progress. One file per checkpoint, written as work lands.

Both folders are intentionally empty until the first milestone is cut — the `.gitkeep` files exist only so the structure survives git.
